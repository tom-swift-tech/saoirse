# Proposals queue

Saoirse places self-modification proposals here when crossing a Tier 0 (Engram
source) or Tier 1 (committed tools/skills) governance boundary. See
[../SYSTEM.md](../SYSTEM.md) governance section.

Each proposal: the diff, the test results, and a VECTOR-scored rationale. Saoirse
stops and waits for an approval token. No gate is crossed without one.

(Empty by design — the queue exists before there is anything to propose, so the
gate is structural from day one rather than retrofitted.)
